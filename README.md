# DMSBooks

Aplicação full stack para cadastro e gerenciamento de livros e usuários. A interface permite listar, adicionar, editar e remover registros.

## Tecnologias

- **Frontend:** React
- **Backend:** Node.js e Express
- **Banco de dados:** MySQL

## Estrutura

O código da aplicação está em \`DMSBOOKS - Copia/\`:

- \`backend/\` — API e integração com MySQL
- \`client/\` — aplicação React

## Executar localmente

Requisitos: Node.js e MySQL. Configure o banco de dados e as credenciais usadas pelo backend antes de iniciar a aplicação.

Em um terminal, instale e inicie o backend:

\`\`\`bash
cd "DMSBOOKS - Copia/backend"
npm install
npm start
\`\`\`

Em outro terminal, instale e inicie a interface:

\`\`\`bash
cd "DMSBOOKS - Copia/client"
npm install
npm start
\`\`\`
